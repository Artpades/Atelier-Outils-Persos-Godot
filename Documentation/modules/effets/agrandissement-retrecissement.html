🦣_ScaleSystem - Effets Spéciaux et Sensations - Documentation

Module Agrandissement - Rétrécissement : faire grossir ou rapetisser un objet en douceur, puis le ramener à sa taille.

Godot 4.7+ Bibliothèque bin/fx 1 classe : FXChangeSize 2D, 3D & interface

📝 Présentation

Un bouton qui grossit au survol, un objet ramassable qui « pulse », un ennemi qui enfle avant d'exploser, une pièce qui rapetisse en disparaissant : ces animations d'échelle demandent un Tween, un pivot centré pour les éléments d'interface, et un retour propre si l'animation est interrompue. Ce module en fait un effet réglable dans l'inspecteur : une taille à atteindre, une taille de repos, une courbe.

Pour qui ? Les intégrateurs d'interface et les game designers qui veulent des retours de survol ou d'interaction sans écrire de Tween.

Ce que ce module n'est pas
  • Pas une déformation : l'échelle reste uniforme. Pour étirer ou écraser selon le mouvement, voir 🪗 Squash and Stretch.
  • Pas une boucle : un aller au jeu, un retour à l'arrêt. Pour une pulsation, enchaîner jeu et arrêt (voir exemple).

⚙️ Mode d'emploi

Objectif : un bouton qui grossit au survol.

  1. Ajouter un PlayerFX sous le Button, avec un FXChangeSize dans special_effects.
    le bouton (parent) est la cible ; son pivot sera automatiquement placé au centre.
  2. Régler final_scale = 1,15 et duration = 0,15.
    un grossissement léger et rapide se lit comme un retour d'interface ; la courbe Back par défaut ajoute un petit rebond.
  3. Relier les signaux du bouton (onglet Nœud, ou par code) : 
    func _ready() -> void:
	$Bouton.mouse_entered.connect($Bouton/PlayerFX.play)
	$Bouton.mouse_exited.connect($Bouton/PlayerFX.stop)
    le jeu anime vers final_scale, l'arrêt vers original_value (1) ; une sortie rapide interrompt proprement l'agrandissement.

💻 API Accessible

Référence générée depuis doc_classes/FXChangeSize.xml. Éléments internes, non exposés : le Tween en cours (interrompu par le suivant) et _tween_scale_to. Les méthodes héritées sont documentées dans ✨ Socle des effets.

📌 Exemples d'utilisation

Comment je fais rapetisser un objet ramassé avant de le supprimer ?

func ramasser() -> void:
	var disparition := FXChangeSize.new()
	disparition.final_scale = 0.0
	disparition.duration = 0.25
	disparition.transition = Tween.TRANS_BACK
	disparition.ease_type = Tween.EASE_IN     # léger gonflement, puis rétrécissement
	$PlayerFX.special_effects = [disparition]
	$PlayerFX.play()
	await get_tree().create_timer(disparition.duration).timeout
	queue_free()

Comment je fais « pulser » un objet ?

Un aller-retour : jeu, puis arrêt au bout de la durée. Le même code en boucle donne un battement.

func pulser() -> void:
	$PlayerFX.play()
	await get_tree().create_timer(0.15).timeout
	$PlayerFX.stop()

Comment je l'utilise sur un objet qui n'est pas à l'échelle 1 ?

original_value n'est pas lu sur l'objet : le régler à son échelle de repos.

var grossir := FXChangeSize.new()
grossir.original_value = $Arbre.scale.x   # ex. 3.0
grossir.final_scale = $Arbre.scale.x * 1.1

Comment je combine agrandissement et son ?

var grossir := FXChangeSize.new()
var clic := FXAudio.new()
clic.stream = preload("res://sons/survol.wav")
grossir.effects_on_play_fx = [clic]
$Bouton/PlayerFX.special_effects = [grossir]

🚧 Limitations

  • L'échelle d'origine n'est pas mémorisée : l'arrêt anime vers original_value sur tous les axes. Une échelle non uniforme ou un sprite retourné (scale.x = -2) est perdu (vérifié : (-2, 1) devient (1, 1) après jeu et arrêt). Retourner un enfant plutôt que la cible.
  • Pivot modifié sur un Control : pivot_offset est placé au centre et le reste après l'effet. Si la taille du Control change ensuite, le pivot n'est recalculé qu'au jeu suivant.
  • Rien ne se passe hors de l'arbre : si la cible n'est pas dans l'arbre de scène, ni animation ni changement immédiat.
  • Le Tween appartient à la cible : il se fige en pause (sauf process_mode = ALWAYS sur la cible) et suit Engine.time_scale.
  • Dans un conteneur, l'échelle d'un Control n'est pas prise en compte par la mise en page : l'élément agrandi chevauche ses voisins (c'est souvent l'effet voulu).
  • Aucun signal de fin : attendre duration. fx_played est émis au début.
  • Conflit avec tout ce qui modifie aussi l'échelle (FXStretchAndSquash, animation) ; et une même instance jouée sur deux cibles interrompt l'animation de la première.

🏗️ Architecture

Composants et communication

  • FXChangeSize surcharge _play et _stop d'Effect, qui appellent tous deux _tween_scale_to : arrêt du Tween précédent, création d'un Tween sur la cible qui anime scale (Vector2 ou Vector3 selon le type).
  • Aucune mise à jour par frame : l'effet fonctionne aussi dans effects_on_stop_fx.

Dépendances et couplage

  • Hérite d'Effect ; aucune autre dépendance.

Décisions de conception

ChoixPourquoi (ne pas « corriger » sans en tenir compte)
Tween créé sur la cibleArrêté automatiquement si la cible est libérée : pas d'animation vers un nœud supprimé.
Tween précédent tué avant le suivantUn arrêt pendant l'agrandissement lancerait sinon deux animations concurrentes sur scale.
Taille de repos réglée (original_value), non capturéeUn survol rapide répété capturerait une échelle intermédiaire et l'objet dériverait ; une valeur fixe garantit le retour exact.
Pivot centré sur les ControlLe pivot par défaut est le coin haut-gauche : un bouton grossirait vers le bas à droite.
