GameplayToolkit · Documentation

Outils et systèmes de gameplay pour Godot 4.7, écrits en C++ (GDExtension) et répartis en modules indépendants.

Comment lire cette documentation

Chaque page de module suit la même structure : Présentation → Installation → Mode d'emploi → API → Exemples → Limitations → Architecture → Changelog. Les tableaux d'API sont générés depuis doc_classes/*.xml : ils sont identiques à l'aide intégrée de l'éditeur Godot (F1).

La barre sous chaque module indique la part de sa référence XML déjà rédigée. Les modules grisés n'ont pas encore de page.

✍️ Ajouter ou mettre à jour une page

  1. Rédiger la référence de chaque classe dans doc_classes/<Classe>.xml (générée vide par scons ou scons gen_doc).
  2. Régénérer les données de l'API : 
    python Documentation/generer_api.py
  3. Copier Documentation/_gabarit-module.html vers Documentation/modules/<catégorie>/<module>.html et remplir chaque section en suivant les consignes qu'il contient.
  4. Renseigner le champ page du module dans Documentation/assets/modules.js.
Pages statiques HTML/CSS/JS : ouvrir Documentation/index.html directement dans un navigateur, aucun serveur n'est nécessaire.
